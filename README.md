# Megamind

> **Note:** This repository is currently a work in progress, so this documentation is subject to updates.

**Megamind** is a personal, local Retrieval-Augmented Generation (RAG) system. It utilizes Ollama and Qdrant to perform hybrid searches (semantic and keyword mappings), allowing you to query your database using natural language.

---

### Key Capabilities

* **Local Execution:** Fully local processing for data privacy and control.
* **Hybrid Search:** Combines semantic and keyword-based retrieval for more accurate results.
* **Multi-Source Ingestion:** Supports a variety of data formats, including:
  * Websites
  * Reddit threads
  * YouTube videos
  * PDFs
